# SyncRoom – Decentralised Music Listening Room

## Project Description
SyncRoom is a peer-to-peer music listening room application where users can create or join rooms, listen to music and communicate with other participants.

## Technologies Used
- HTML
- CSS
- JavaScript
- WebRTC (planned integration)

## Features
- Create and join rooms using a room code
- Username validation
- Local music upload and playback
- Chat interface
